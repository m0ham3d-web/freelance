# 💼 Mini Freelance Platform

A modern mini freelancing platform designed to connect clients with talented freelancers and make project management easier.

## 🌐 Live Demo

[View Live Demo](https://m0ham3d-web.github.io/freelance/)

## 📌 About The Project

Mini Freelance Platform is a front-end web application that provides a simple environment for clients to publish projects and freelancers to discover opportunities and submit proposals.

The interface supports Arabic and English, with a responsive layout and customizable themes.

## ✨ Features

- 🌍 Arabic and English language support
- 🌙 Dark and Light mode
- 🔎 Search for available projects
- 🗂️ Filter projects by category
- 👨‍💻 Freelancers section
- 📝 Publish new projects
- 💰 Project budget and deadline fields
- 📩 Submit project proposals
- 📋 Project details modal
- 📱 Responsive user interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome

1. Clone the repository:

```bash

```

2. Open the project folder.

3. Run `index.html` using your browser or a local development server.
